Step 12 – Identify what needs storing (10 minutes)

Look at your five pages. What information is repeated or changes often? Typically:

  • Your profile (name, programme, bio)
  • Your skills
  • Your hobbies
  • Your top movies
  • Messages people send you through the contact form

Write these down in your notebook. This is the list of things your database will store.

Step 13 – Draw your ER diagram (15 minutes)

One person (profile) has many skills, hobbies, movies and enquiries. This is a one-to-many relationship. Sketch this on paper:

            +-----------+
            |  PROFILE  |
            |-----------|
            | profile_id|  <-- Primary Key (PK)
            | full_name |
            | programme |
            | bio       |
            +-----+-----+
                  | 1
   +--------+-----+-----+----------+
   | many   | many      | many     | many
+--v---+ +--v----+  +---v---+  +---v-----+
|SKILL | |HOBBY  |  |MOVIE  |  |ENQUIRY  |
+------+ +-------+  +-------+  +---------+
 each has its own PK and a Foreign Key (FK): profile_id

Primary Key (PK) = a column that uniquely identifies each row (like an ID number).
Foreign Key (FK) = a column that links a row back to its owner (e.g. which profile a skill belongs to).

Take a clear photo of your sketch. You will submit it.

Step 14 – Create the tables (20 minutes)

Open DB Browser for SQLite, click New Database, name it portfolio.db and save it inside a folder called data in your my-portfolio folder.

Click the Execute SQL tab, paste ALL of the code below, then click Run (the play button).

CREATE TABLE profile (
  profile_id INTEGER PRIMARY KEY,
  full_name  TEXT NOT NULL,
  programme  TEXT,
  bio        TEXT
);
CREATE TABLE skill (
  skill_id   INTEGER PRIMARY KEY,
  profile_id INTEGER NOT NULL,
  skill_name TEXT NOT NULL,
  level      TEXT,
  FOREIGN KEY (profile_id) REFERENCES profile(profile_id)
);
CREATE TABLE hobby (
  hobby_id    INTEGER PRIMARY KEY,
  profile_id  INTEGER NOT NULL,
  hobby_name  TEXT NOT NULL,
  description TEXT,
  FOREIGN KEY (profile_id) REFERENCES profile(profile_id)
);
CREATE TABLE movie (
  movie_id     INTEGER PRIMARY KEY,
  profile_id   INTEGER NOT NULL,
  title        TEXT NOT NULL,
  release_year INTEGER,
  my_rank      INTEGER,
  why_i_love_it TEXT,
  FOREIGN KEY (profile_id) REFERENCES profile(profile_id)
);
CREATE TABLE enquiry (
  enquiry_id   INTEGER PRIMARY KEY,
  profile_id   INTEGER NOT NULL,
  sender_name  TEXT NOT NULL,
  sender_email TEXT NOT NULL,
  message      TEXT NOT NULL,
  sent_at      TEXT DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (profile_id) REFERENCES profile(profile_id)
);
You should see “Query executed successfully”. If you get an error, you probably missed a semicolon or bracket. Copy the code again carefully.

Step 15 – Enter your records (15 minutes)

Each row in a table is a record; each column is a field. Add yourself first, then your data. In DB Browser, go to Browse Data and click New Record, OR run these INSERT statements in the Execute SQL tab.

Replace the sample text with your own information:

INSERT INTO profile (full_name, programme, bio)
VALUES ('Your Name', 'BSc. Fisheries and Aquaculture', 'Your short bio');

INSERT INTO skill (profile_id, skill_name, level)
VALUES (1, 'Microsoft Word', 'Advanced'),
       (1, 'HTML and CSS', 'Beginner');

INSERT INTO hobby (profile_id, hobby_name, description)
VALUES (1, 'Football', 'Weekend matches with friends');

INSERT INTO movie (profile_id, title, release_year, my_rank, why_i_love_it)
VALUES (1, 'Your Movie 1', 2010, 1, 'Because...'),
       (1, 'Your Movie 2', 2015, 2, 'Because...');

Add all 5 movies, at least 3 hobbies and at least 5 skills. Notice that profile_id = 1 in each row is the foreign key linking the record back to you.

Tip: if you prefer clicking, use the Browse Data tab and the New Record button. Both ways are fine.

Step 16 – Ask questions with SQL (20 minutes)

Run each query in DB Browser (Execute SQL tab) and write the output (or a screenshot) in your lab report.

-- 1. Show my full profile
SELECT * FROM profile;

-- 2. My movies in rank order (sorting)
SELECT title, release_year FROM movie ORDER BY my_rank;

-- 3. Only movies released after 2010 (filtering)
SELECT title FROM movie WHERE release_year > 2010;

-- 4. Combine tables: my name with each of my hobbies (relationship)
SELECT profile.full_name, hobby.hobby_name
FROM profile
JOIN hobby ON hobby.profile_id = profile.profile_id;

-- 5. How many skills do I list?
SELECT COUNT(*) FROM skill;

Think: if your movie list were stored in this database, how would the Movies page change when you update a row? Answer: you would edit one record and the page would rebuild itself. No need to rewrite HTML. That is the heart of a dynamic website.

Step 17 – Connect the contact form to the database (concept and guided demo)

Concepts: web forms, client-server interaction, backend.

You will not write backend code. Your instructor has provided a prepared starter application. Your job is to understand the journey of a message:

Visitor types message  ->  Browser (client) sends form data
   ->  Web server receives it  ->  Server script validates it
   ->  INSERT INTO enquiry ...  ->  Database stores it
   ->  Server replies "Thank you!"  ->  Browser shows confirmation

Part A – Download the starter from GitHub (no command line)

1
Open your web browser and go to: https://github.com/Kiotolabs/kioto-ics2216-lab02
2
On that page, click the green button called Code.

Right-click that ZIP file and choose Extract All… (on Windows) or double-click it (on Mac). Choose your Desktop as the destination and click Extract.

You will now have a folder called kioto-ics2216-lab02-main on your Desktop. Open it. Inside you will see files like config.php, setup.php, submit.php, and a folder called data.

After this, contact.html and submit.php should be in the same folder. That is very important.

Part B – Run the backend on your computer

1
Start Apache in XAMPP or Laragon.
2
Make sure your my-portfolio folder is inside the web server folder:
XAMPP: C:\xampp\htdocs\my-portfolio
Laragon: C:\laragon\www\my-portfolio
3
Open your browser and type: http://localhost/my-portfolio/setup.php and press Enter.
4
You should see “Database ready”. This created a file called portfolio.db inside the data folder.
5
Open the file config.php in Notepad (or any text editor). Find the line const ADMIN_PASS = 'change-me-please'; and change the password to something only you know. Save the file.
Do not share this password. The default one is intentionally weak and shows a warning on the login page.

Part C – Add the contact form to your contact page

Open your contact.html in your text editor. Scroll to the bottom of the <main> section (just before </main>) and paste this form:

<section class="card">
  <h2>Send me a message</h2>
  <form action="submit.php" method="post">
    <p><label for="name">Your name</label><br>
       <input type="text" id="name" name="sender_name" required maxlength="80"></p>
    <p><label for="email">Your email</label><br>
       <input type="email" id="email" name="sender_email" required></p>
    <p><label for="msg">Message</label><br>
       <textarea id="msg" name="message" rows="4" required maxlength="1000"></textarea></p>
    <!-- spam trap: humans leave this empty -->
    <div style="position:absolute;left:-9999px" aria-hidden="true">
      <label>Leave empty<input type="text" name="website" tabindex="-1" autocomplete="off"></label>
    </div>
    <button class="btn" type="submit">Send</button>
  </form>
</section>
You can also copy this from the file snippets/contact-form.html that came with the download.

Save contact.html.

Part D – Test the full journey

1
Open http://localhost/my-portfolio/contact.html in your browser.
2
Fill in the form with a test name, email and message. Click Send.
3
You should see “Message received!”. That means the server saved your message.
4
Open http://localhost/my-portfolio/admin.php. Enter the password you set in config.php. Click Login.
5
You should see your test message in the table. Congratulations – your contact form is connected to your database.

If you added movies to your database (Step 15), open http://localhost/my-portfolio/movies-live.php. Your movies will appear, pulled live from the database. Edit a row in DB Browser and refresh the page – it changes without editing HTML.
